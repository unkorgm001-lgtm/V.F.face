# SocialHub — Dark Mode Social Feed

A responsive Facebook-inspired social media interface built with a dark-mode color palette (`#18191A` canvas and `#242526` elevated cards).

## Files Included
- `index.html` — Three-column layout with sticky top navigation, stories row, post composer, interactive news feed, and online contacts sidebar.
- `styles.css` — Self-contained dark-mode stylesheet with responsive breakpoints for desktop, tablet, and mobile screens.
- `script.js` — Interactive post publishing, like toggling, and live comment threads.
